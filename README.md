ИНСТРУКЦИЯ ПО ЗАПУСКУ
1. Установка и сборка не требуются: проект на чистом HTML, CSS и JavaScript, без фреймворков и серверной части.
2. Открыть public/signal/index.html в браузере (Chrome, Edge, Firefox, Safari) двойным кликом.
   Рекомендуется простой локальный сервер, например: npx serve public/signal или python -m http.server -d public/signal
3. На странице входа выбрать роль в блоке «Быстрый вход» (Сотрудник, Руководитель, Администратор)
   или войти по e-mail и демо-паролю demo1234 (учётные записи указаны в поле «Тестовые ключи»).
4. Сброс к исходным данным: роль «Администратор» → вкладка «Данные» → «Сбросить демо-данные».

ДЕМО: ЧТО РЕАЛИЗОВАНО / ИМИТАЦИЯ / В ПЛАНАХ

РЕАЛИЗОВАНО (работает в приложении)
- Три роли: сотрудник, руководитель, администратор, у каждой свой кабинет и права.
- Подача обращения сотрудником, отслеживание статуса, добавление вложений.
- Канбан-доска со статусами: перенос карточек мышью, пальцем (долгое нажатие), клавиатурой и через меню «Переместить в…».
  Порядок карточек внутри колонки сохраняется, прокрутка не сбрасывается.
- Группировка доски по статусам и по ответственным, табличный вид, фильтры и поиск.
- Смена статуса с обязательным комментарием для статусов, где он нужен (уточнение, выполнено, отклонено, закрыто).
- Отмена последнего действия (Ctrl+Z), всплывающие уведомления.
- Авто-маршрутизация обращений по категории ответственному, ручная передача, перераспределение очереди.
- SLA по приоритетам, аналитика и отчёты, настройка прав.
- Светлая и тёмная темы, адаптив под телефон и планшет.
- Экспорт всех данных в JSON, сброс демо-данных.

ИМИТАЦИЯ (в MVP показано упрощённо)
- Уведомления: колокольчик в шапке имитирует рассылку, реальных писем, мессенджеров и push нет.
- Авторизация: учебная, на стороне браузера, без серверной проверки и защиты данных.
- Хранилище: localStorage браузера. Данные одного пользователя не видны на другом устройстве.
- Демо-данные (обращения, сотрудники, организационная структура) вымышленные.

В ПЛАНАХ
- Интеграция с Битрикс24: уведомления о смене статуса, новых комментариях и просрочке, постановка задач.
- Интеграция с 1С: Управление торговлей: загрузка оргструктуры и справочника номенклатуры.
- Корпоративный вход через LDAP/AD (SSO).
- Серверная часть и база данных: общее хранилище, настоящая авторизация, журнал аудита.
- Автоматический расчёт SLA по дате первого ответа, регулярные отчёты для руководства.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
- Данные хранятся только в браузере: очистка кеша или другой браузер означает пустое или исходное состояние.
- Нет серверной части: несколько пользователей не могут работать с общими данными одновременно.
- Вложения и все данные ограничены объёмом localStorage (около 5 МБ).
- Уведомления и интеграции с внешними системами только имитируются.
- Не проверялась работа в старых браузерах (до 2020 года).
